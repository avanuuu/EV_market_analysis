ℹ️ Tableau Desktop Connection & Deployment Instructions

The Tableau workbook file tableau/ev_market_analysis.twb is fully pre-configured in this repository.

  • Local Desktop Evaluation: Open tableau/ev_market_analysis.twb in Tableau Desktop or Tableau Public. It is pre-linked to the verified dataset data/processed/ev_market_master_tableau.csv.
  • Enterprise MySQL Live Connection: In Tableau, select Data > New Data Source > MySQL, enter host localhost:3306, database ev_market_db, and connect to view v_executive_market_kpis.
  • Custom Embed URL: If you publish the workbook to your own Tableau Server or Tableau Public account, update TABLEAU_DASHBOARD_URL in your .env file.
