System Architecture & Design

About the Electric Vehicle Market Analysis Platform

An end-to-end data analytics, business intelligence, and web engineering capstone project designed for academic evaluation, portfolio presentation, and automotive strategy demonstration.

Required Technology Stack Implementation

Programming & Backend

Python 3.11 & Flask 3.1
Modular application factory architecture, parameterized SQL querying, REST API endpoints, security headers, and production-safe debug configurations.

Relational Database

MySQL 8.0+ / 9.0+ & SQLAlchemy / PyMySQL
Normalized 3NF relational schema with 6 core tables, InnoDB engine, utf8mb4 encoding, foreign keys, CHECK constraints, composite indexes, and analytical views.

Business Intelligence & Visualization

Tableau Desktop / Tableau Public
Dedicated workbook XML (tableau/ev_market_analysis.twb) featuring Dashboards A, B, C, calculated fields, and a 5-scene analytical story.

Testing & Data Quality

pytest & Python unittest
Automated test suites covering web routes, HTTP status codes, data pipeline integrity, numerical boundaries, and database query executions.

Academic & Portfolio Evaluation Highlights

  • Authentic Data Foundations: Real data sourced from OpenEV Data canonical repository, IEA Global EV Outlook, and EV-Database. Synthetic benchmarks are transparently isolated, documented, and labeled.
  • Relational Purity: Normalized MySQL schema enforcing primary keys, foreign keys, CHECK constraints, and optimized index trees.
  • Advanced SQL Engineering: 14 production queries utilizing CTEs, LAG(), DENSE_RANK(), running sums, safe division with NULLIF(), and multi-table joins.
  • Cohesive Visual Design: Professional executive layout avoiding generic placeholder components or mockups.
  • Version Control Ready: Clean Git repository layout with explicit .gitignore, credential isolation, and comprehensive technical documentation.
